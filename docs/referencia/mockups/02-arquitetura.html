Arquitetura do Apura (MVP)

Tudo roda no navegador. As caixas são pastas do projeto; as setas mostram por onde os dados passam. Tracejado = evolução futura, fora do MVP.

índices/

Cópia embutida no app · busca silenciosa no BCB pelo navegador · cache local · índices congelados por cálculo. Cada valor guarda fonte e data de obtenção. Sem inserção manual.

ui/ (tela única, layout A)

Formulários das 5 seções, tabela editável, lançamento em lote, textos de ajuda. Cada alteração recalcula na hora.

metodologias/

Metodologias de encargos em arquivos JSON versionados (padrão: TJMS/SAJ v1), com períodos, índices e taxas. Ajustes do usuário ficam marcados na tela e no arquivo; o relatório descreve só o que foi aplicado.

Cálculo (um único objeto, serializável em JSON)

Cabeçalho (defensor, órgão, processo, partes) · base dos alimentos · lançamentos (prestações e amortizações) · metodologia aplicada · multa/honorários · data de elaboração · observações. É o "estado completo" do cálculo: guardar, reabrir e editar no futuro é só armazenar este objeto.

↓

motor/ (funções puras)

Recebe o Cálculo + tabela de índices e devolve o Resultado. Sem rede, sem relógio, sem tela. Aritmética decimal exata, arredondamento definido, testado contra casos de referência.

Resultado

Cada lançamento atualizado (base, fator, corrigido, juros, atualizado), índices e dias de juros usados, totais (prestações − amortizações, multa, honorários), meses sem índice, avisos.

↓

relatório/

Mesmo HTML para a tela e para o PDF (Imprimir → Salvar como PDF). Faixa verde com a marca, indicadores-resumo, memória mensal, metodologia gerada a partir dos parâmetros + observações, matriz de índices, rodapé com fontes e "Apura" discreto.

Publicação: GitHub privado → Cloudflare Pages (ou Netlify) publica automaticamente → link para os testadores. No seu Mac: um comando abre a mesma coisa.

Futuro · servidor + banco + login

Guarda o JSON do Cálculo por equipe; Entra ID; administrador de perfis. O motor não muda.

Futuro · SAJ / Solar / MNI

Preenchem o cabeçalho do Cálculo (processo, partes, assistido).

Futuro · outros tipos

Honorários, danos morais, cálculo livre: novos perfis e novas formas de gerar prestações, mesmo motor.
